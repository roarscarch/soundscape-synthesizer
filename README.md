# Soundscape Synthesizer

> Ambient music from any phrase

Generate infinite, evolving ambient soundscapes from a single seed phrase using a deterministic wave function collapse algorithm.

## Stack
- Language: **python**
- sounddevice, numpy

## Features
- Seed phrase to unique, non-repeating audio stream
- Multiple biomes (forest, ocean, space) with custom wave tables
- Real-time panning and volume LFOs for organic movement
- Sleep timer and fade-out for background use
- Export current soundscape as WAV file

## Architecture
Uses a seeded PRNG to drive a wave function collapse on a 2D grid of audio grains, ensuring deterministic but ever-changing output without repeating patterns.
